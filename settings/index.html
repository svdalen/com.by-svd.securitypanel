Keypad users

Each person has their own code of 4 to 8 digits. Codes are stored hashed and never shown again; leave the code field empty to keep it. After 5 wrong attempts a keypad locks for 30 s, doubling each time.

Panic code

A user types their normal code followed by these digits. The alarm disarms as usual and nothing shows on screen, but the flow trigger A panic code was entered fires so you can warn someone silently. Leave empty to disable.

Codes and protection

The panel's device tile and Homey's built-in "Set state" card cannot ask for a code. Choose what they may do. For a shared tablet, log the Homey app in as a Guest: guests can control devices and start flows but cannot change settings. Combine that with a read-only tile and "flows need a code", and the tablet can only arm.

Arming needs a codeKeypad widget, physical keypads and the API. Disarming always needs one.
